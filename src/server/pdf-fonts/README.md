# Fonts for invoice PDFs

The server's headless browser has no fonts of its own, so these are loaded
before an invoice is turned into a PDF.

- `LiberationMono-Bold.ttf`, `LiberationMono-Regular.ttf`: same letter widths
  as Courier New, the font the printed invoice uses.
  Digitized data copyright (c) 2010 Google Corporation with Reserved Font
  Arimo, Tinos and Cousine. Copyright (c) 2012 Red Hat, Inc. with Reserved
  Font Name Liberation.
- `NotoSans-Bold.ttf`: for the rupee sign (₹), which Liberation Mono lacks.
  Copyright 2010-2020 Google Inc. / Google LLC.
